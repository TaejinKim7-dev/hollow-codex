## 1. 시나리오에서 나온 비주얼 뼈대

### 세계
대륙 **알마**. 300년 전 한 순례자가 열석(둥글게 선 돌) 사이로 와서 여덟 미덕을 몸소 보이고 **빈 경전**만 남기고 떠났다. 여덟 교단이 각자 주석을 써 넣었고 주석이 법이 됐다. "아무도 악하지 않지만, 모두 선의로 서로를 옥죄는" 세계다. 원래의 빈 경전은 봉인된 서고에 잠들어 있다.

그림 톤 시사점: 밝은 영웅담이 아니라 **따뜻하지만 어딘가 굳고 낡은 중세** — 채도를 살짝 눌러 통일감을 주는 쪽이 이야기와 맞는다.

### 플레이어와 동료
- 플레이어: 호칭은 "이방인". 외모·복장 묘사는 **설정에 없음** → 디자인 자유. 여행자 차림(외투·지팡이·수첩)을 제안한다. 수첩(=플레이어의 경전)이 핵심 소품이다.
- 동료 엘린(칼라스): 고발관 견습. 고발청에서 자랐고 장부를 관리한다. 복장 힌트: 기록 관련 소도구(필기구·두루마리).
- 나머지 동료 7명은 아직 콘텐츠에 없음(0.2.0 이후 과제).

## 2. 타일 크기·화면 규격 제안

현재 구현: 소스 타일 16×16, 시야 15×11 타일, **정수 배율**(`scale = max(1, floor(min(vw/240, vh/176)))`), 단층 렌더링.

| 선택지 | 1타일 소스 | 화면 15×11 최소 CSS 크기 | 장점 | 단점 |
|---|---|---|---|---|
| 16×16 유지 | 256px 면적 | 240×176 (모든 폰 OK) | 작업량 최소 | 사용자가 이미 "단순 화풍"으로 판정, 얼굴·옷자락 표현 한계 |
| **32×32 (추천)** | 1024px | 480×352 | 고전 16비트 RPG 표준. 얼굴·주름·소품이 읽힘. 정수배율 친화(×2=64, ×3=96) | 세로 폰(360~430px)에서 15칸이 안 들어감 → 좁은 화면은 시야 11×8(352×256)로 자동 축소 구현 필요 |
| 48×48 | 2304px | 720×528 | HD 감성 | 작업량 16의 9배, 픽셀아트보다 일러스트에 가까워짐, 모바일 부담 |

**추천: 32×32 타일.** 근거:
1. plan.md §0의 새 방향("32×32 이상 또는 그만큼 다듬어진")과 일치.
2. 손그림으로 얼굴 표정·직업 소품을 읽히게 하려면 16×16은 너무 좁다.
3. 웹 성능: 타일 한 벌 + 캐릭터 시트 합쳐도 PNG 수십 KB, 기존 5MiB 예산에 무리 없음.
4. 모바일 대응: 시야 타일 수를 화면 크기로 고르는 로직(15×11 ↔ 11×8)은 viewport.ts 한 곳 수정. 이건 구현 과제로 S 설계에 넣는다.

### 캐릭터 프레임
- **안 A (추천): 32×32, 타일 안에 온전히 들어가는 인물.** 발 위치 관리가 단순하고 기존 그리기 로직 그대로.
- 안 B: 32×48(머리가 위 칸으로 넘치는 고전 RPG 비율). 보기는 좋지만 그리기 순서·충돌 처리를 손봐야 한다.
- 걷기: 방향당 3프레임(정지·왼발·오른발) 표준. 1차는 **플레이어만 4방향×3프레임(12프레임)**, NPC는 4방향 정지(4프레임)로 시작해 판정 후 확장.

### 팔레트
spec §5 "팔레트는 한 벌로 통일". 제안:
- **안 A (추천): Sweetie-16(CC0) 16색 기반** — 적은 색으로 통일감 확보, 초보 손그림에서 색 산만함 방지.
- 안 B: DawnBringer-32(CC0) 32색 — 표현 여유, 통일 난이도↑.
- 안 C: 직접 제작 — 완전 자유, 실패 위험↑.
어느 쪽이든 최종 팔레트는 저장소에 `.gpl` 또는 hex 목록으로 고정한다.

## 3. 시나리오별 그릴 목록 (전체 인벤토리)

### 3-1. 지형 타일 (17종 — 현재 `content/tiles.yaml`의 문자 전부)
| 문자 | 쓰임 | 그릴 것 |
|---|---|---|
| `.` | 풀밭(기본 땅) | 풀 바닥 + 변형 2~3(꽃·돌멩이) |
| `,` | 길 | 흙길 |
| `:` | 돌길·마당 | 돌바닥 |
| `=` | 다리·마루 | 나무 마루/다리 |
| `~` | 물(통행 불가) | 물 + 물가 접합 |
| `T` | 나무 | 나무(투명 위쪽, **땅 층 필수**) |
| `^`·`#` | 산·벽(불가) | 바위산/성벽 |
| `+` | 문 | 문 |
| `o` | 돌·소품 | 돌 |
| `L` | 카운터·책상류 | 확인 후 제작 |
| `S` | 소품(통행 가능) | 확인 후 제작 |
| `_` | 던전 바닥 | 어두운 돌바닥 |
| `%` | 던전 벽 | 어두운 벽 |
| `>`·`<` | 계단 | 오르내리는 계단 |

렌더링 구조 주의: 지금은 칸마다 그림 하나라 투명 그림 아래가 검정이다. **땅 층 + 물건 층 분리**는 S 설계 과제이며, 그림 제작 시 나무·소품은 투명 배경으로, 땅은 불투명으로 따로 낸다.

### 3-2. 캐릭터
1. 플레이어(이방인): 4방향×3프레임. 외투·지팡이·수첩.
2. NPC 직업 아키타입(현재 81 NPC가 12개 스프라이트를 공유): 노인 문지기, 사냥꾼, 고백관/관리, 서기·필경사, 사제·수도사, 상인·주모, 제빵·농부, 전사·투사, 장인(석공·대장장이), 과부, 아이, 은자. 각 4방향 정지로 시작.
3. 엘린(동료): 고발관 견습 차림.

### 3-3. 크리처 9종 — §1 표 기반, 사람 7 + 존재 2.

### 3-4. 고유 소품·건물 — §1 "고유 소품" 목록.

## 4. 제작 순서 제안

| 차수 | 내용 | 종료 조건 |
|---|---|---|
| 1차(파일럿) | 팔레트 확정 + 풀·흙길·물·나무·집(벽/지붕/문) + 플레이어 12프레임 | 들판·칼라스 외부에 적용해 스크린샷, **사용자 시각 판정** |
| 2차 | NPC 12종 + 늑대·도굴꾼 + 칼라스 실내·고발청·서고 | 칼라스 전체 플레이 가능, 스크린샷 판정 |
| 3차 | 8마을 차별화 + 마을 상징 건물 + 나머지 크리처 7종 | 마을별 구분 스크린샷 판정 |
| 4차 | 열석 고리·빈 경전·고백석 + 전투 화면 정리 + 던전 | 전 장면 스크린샷 판정 |

각 차수는 AGENTS.md §9대로 스크린샷을 에이전트가 직접 보고 `docs/screenshots/`에 남기고, 사용자 판정 전까지 완료로 적지 않는다.

## 5. 사용자에게 물을 것
1. 타일 크기: 32×32(추천) / 16×16 / 48×48
2. 캐릭터 프레임: 32×32(추천) / 32×48

5. 1차 파일럿 범위 승인 여부.
