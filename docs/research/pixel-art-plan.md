# A-1 시나리오 근거 그림 인벤토리 (R-0 부록)

작성일: 2026-10-18 · 작성: Kimi · 상태: 참고 자료.
역할: **`docs/research/art-direction.md`(R-0)의 근거 부록**이다. 규격·화풍·우선순위 제안과 사용자 의견란은 R-0 문서 하나로 통일했다. 이 문서는 R-0의 목록이 실제 콘텐츠에서 나온 것임을 보이는 인용 근거와, R-0에 없는 세부 인벤토리(크리처 설정, 지형 문자 17종, 고리 지리)를 담는다. 생성 프롬프트를 쓸 때 여기서 설정 문구를 가져간다.

근거 파일: spec §3, `content/strings/ko.yaml`, `content/towns/*`, `content/creatures.yaml`, `content/rings.yaml`, `content/tiles.yaml`.

## 1. 크리처 9종 — 전투 화면에 필요한 전부 (설정 인용)

9종 중 7종이 사람 형태라 사람 기본형 + 소품·색 변형으로 덮인다(R-0 §4 3차의 "기본형 6종" 방식과 일치). 순수 비인간은 늑대뿐이고, 침묵의 파수꾼은 비인간으로 해석할 여지가 있다.

| id | 이름 | 설정 인용 (ko.yaml) | 악? | 그림 힌트 |
|---|---|---|---|---|
| creature.wolf | 굶주린 늑대 | "굶주렀을 뿐, 악하지 않다. 겁먹은 짐승은 화살보다 먼저 이해를 기다린다" | 아님 | 마른 몸, 움츠린 자세. 들판 |
| creature.robber | 서고 도굴꾼 | "자기 사연을 대며 벽을 뚫고 들어온 자들. 탐욕이 그들의 걷는 길을 앞질렀다" | 예 | 도구(쇠지렛대), 낡은 복면 |
| …compassion-beggar | 굶주린 거지 | "그의 손은 게으르지 않고, 다만 빈손일 뿐이다" | 아님 | 빈 손을 내민 자세 |
| …valor-duelist | 떠돌이 결투가 | "이기려 싸우지 않고, 살아 돌아오는 법을 보여 주려는 자" | 아님 | 낡은 검, 지친 눈 |
| …justice-mourner | 슬픔에 잠긴 조문객 | "낯선 이를 도둑으로 오인하는 것은 슬픔 때문이다" | 아님 | 상복, 고개 숙임 |
| …sacrifice-penitent | 회개의 고행자 | "제단 앞에서 등을 채찍질한다" | 아님 | 고행복, 채찍 |
| …honor-braggart | 자랑질하는 결투가 | "이기는 것이 곧 자랑이라 믿어, 누구든 칼자루를 내미는 자에게 덤벼든다" | 예 | 화려한 문장, 도발 자세 |

전투 맥락: spec §4.5 — 생물 도감이 "이 존재는 정말 악한가"를 알려 주고, 악하지 않은 존재를 죽이면 행실에 기록된다. 그래서 **악하지 않은 크리처는 위협적이기보다 측은하게** 그려야 판단 유도가 안 꼬인다.

## 2. 지형 문자 17종 — `content/tiles.yaml` 전수

| 문자 | 쓰임(맵에서의 역할) | 통행 | 그릴 것 |
|---|---|---|---|
| `.` | 풀밭 기본 땅 | 가능 | 풀 바닥 + 변형 |
| `,` | 흙길 | 가능(비용 2) | 흙길 |
| `:` | 돌길·마당 | 가능 | 돌바닥 |
| `=` | 마루·다리 | 가능 | 나무 마루 |
| `~` | 물 | 불가 | 물 + 물가 접합 |
| `T` | 나무 | 불가 | 나무(투명 배경, 땅 층 위) |
| `^`·`#` | 산·벽 | 불가 | 바위·벽 |
| `+` | 문 | 가능 | 문 |
| `o` | 돌 소품 | 불가 | 돌 |
| `L` | 카운터·책상류 | 불가 | 실내 가구 |
| `S` | 소품 | 가능 | 밟을 수 있는 소품 |
| `_` | 던전 바닥 | 가능 | 어두운 돌바닥 |
| `%` | 던전 벽 | 불가 | 어두운 벽 |
| `>`·`<` | 계단 | 가능 | 계단 |

주의: 현재 렌더러는 칸마다 그림 하나라 투명 그림 아래가 검정(0.1.0 검은 사각형 결함). **땅 층 + 물건 층 분리**는 S 설계 과제이며, 생성 시 땅 타일은 불투명, 나무·소품은 투명 배경으로 따로 낸다.

## 4. 마을별 분위기 인용 모음 (프롬프트 소재)

R-0 §1 표의 "굳은 모습" 열의 근거다. 생성 프롬프트의 분위기 문구는 여기서 가져온다(단, 원작 게임·작가 이름은 넣지 않는다, spec §2).

- 칼라스: "고백으로 시작하는 곳" / "기록이 마을을 지킨다" / 광장 등불, 고발청 장부.
- 리오나: "곳간 앞에 사람들이 모였다… 아무도 손을 잡지 않는다" / 빵 냄새, 배급 줄.
- 솔강: "투기장에 사람들이 모였다… 무패의 투사가 물러서지 말라며 창을 겨눈다" / 대장간, 깃발.
- 셀레스: "법정 앞에 달빛이 서늘하다" / 묘지, 조문, "돌에는 거짓을 새길 수 없어서"(석공).
- 디오네: "사랑은 아낌없이 바치는 것" / 제단, 고행, "돌도 놀라서 거짓말을 배웠어"(석공).
- 아르곤: "가문의 이름을 지키는 자리" / 서열 장부, 문장, "술은 이름을 묻지 않네"(주모).
- 엘리아: "명상은 공짜가 아니야" / 명상당, 면허 장부, "정원은 면허가 필요 없어"(정원사).
- 헤론: "침묵." / "우물은 말이 없다" / "나무는 이름을 부르지 않는다" — 대사가 거의 없는 마을.
- 봉인 서고: "만질 수 있는 책이 이제는 이것뿐이라서"(사서) / 도굴꾼이 벽을 뚫은 금지 구역.

## 5. 인물 아키타입 분석 (81 NPC → 기본형 근거)

현재 81 NPC가 스프라이트 12종(town 84–95)을 공유한다. 대사에서 드러나는 반복 직업군: 문지기·노인, 사냥꾼, 고백관·관리, 서기·필경사, 사제·수도사, 상인·주모·제빵, 전사·투사, 장인(석공·대장장이·직조), 과부, 아이, 은자. R-0 §4 3차의 "공용 기본형 6종 + 마을 옷 색" 결정과 양립한다.

- 플레이어 "이방인": 외모 묘사 **설정 없음** → R-0의 제안(망토·지팡이·수첩)이 원안.
- 동료 엘린: "고발관 견습… 어릴 적부터 고발청에서 자랐어요… 장부를 관리해요" → 견습 관복 + 장부 소품 근거.

## 6. 고유 소품 근거
- **열석 고리**: "둥글게 선 돌"들(spec §3.1). 8곳 공통 형태 + 고리별 이름 새김. 세계관 제1 상징.
- **빈 경전**: "순례자가 남긴 경전은 비어 있었다" — 닫힌 경전 소품 + 엔딩의 펼쳐진 빈 페이지.
- **고백석**: 칼라스 성문의 고백 장소(plan.md §0에서 "상자처럼 보인다"고 판정된 소품). R-0 §1의 "고백석과 깨진 등불"이 원안.
- 마을 상징: 곳간(리오나), 투기장(솔강), 법정·묘지(셀레스), 제단(디오네), 가문 문장(아르곤), 명상당(엘리아), 침묵 예배당·우물(헤론), 고발청·옛 서고(칼라스).
