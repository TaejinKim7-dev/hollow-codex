# 배경음악 만드는 방법 정리 (R-2b)

작성: 2026-10-27 · 상태: 방향 정리 + 후보 조사 진행 중

## 지금 확인된 사실
- **ElevenLabs 음악은 무료 요금제에서 안 된다.** `music compose` → `paid_plan_required` ("Music API is not available for free users"). 효과음(35개)은 가능했다(`docs/research/elevenlabs-sfx.md`).
- ElevenLabs 유료로 만든 음악의 상업 사용 조건은 원문 미확인(Music 별도 약관 있음). 사용자는 "비상업 개인 개발"을 허용했지만 공개 저장소(CC-BY-SA)에 커밋하려면 라이선스가 맞아야 한다.
- 소리 방침(`docs/research/audio-assets.md`): 저장소에는 CC0/CC-BY/CC-BY-SA만. 비상업 소리는 `assets-private/`(git 제외)에만.

## 만드는 세 가지 길
| 길 | 방법 | 장점 | 단점 | 비용 |
|---|---|---|---|---|
| **A. 공개 음원 고르기** | OpenGameArt·incompetech·FMA·Wikimedia에서 CC0/CC-BY/CC-BY-SA 곡을 12슬롯에 맞춰 고름. 조사: `docs/research/bgm-candidates.md`(백그라운드 에이전트, 곡마다 원문 라이선스 인용) | 바로 실제 악기 소리, 저장소에 커밋 가능, 무료 | 곡이 남과 겹침, 분위기가 정확히 안 맞을 수 있음, CC-BY는 크레딧 표기 | 0 |
| **B. 직접 작곡 + CC0 샘플 연주** | 오래된 곡을 편곡하거나 새로 쓴 MIDI를 VSCO 2 CE(CC0 실제 악기 샘플)로 렌더링 | 곡이 우리 것, 라이선스 가장 깔끔, 루프·길이 마음대로 | 작곡·렌더링 도구 설치와 손이 많이 감 | 0 |
| **C. ElevenLabs 유료로 생성** | 슬롯별 프롬프트로 `music_v2_5` 생성 | 분위기를 말로 정확히 지시, 빠름 | 유료 요금제 필요, 상업 조건 미확인, AI 생성물 저작권 불확실 | 유료(가격 미확인) |

**추천 순서**: A로 12슬롯 기준 곡을 먼저 채워 게임이 소리를 갖게 한다 → 어울리지 않는 슬롯만 B(또는 사용자가 원하면 C)로 보강.

## 파일 규격(S 설계에서 확정)
OGG 96–128 kbps, 곡당 60–120초 루프, 12곡 합계 약 12 MB 안쪽 → 배포 예산(지금 5 MiB) 상향 또는 마을별 지연 로딩이 필요. 크레딧 표기가 필요한 곡은 게임 크레딧 화면과 README에 정확한 문구로 넣는다. 파일마다 장부(`assets/LEDGER.md`)에 URL·라이선스 원문·날짜.

## 청취·선택
후보 파일은 `assets-private/preview/bgm/`(+`bgm.json`: slot, key, title, artist, license, src)에 받아 실험실(`/hollow-codex/lab/`)에서 듣고 고른다. 고른 곡만 `assets/audio/bgm/`로 옮기고 장부에 기록한다.
