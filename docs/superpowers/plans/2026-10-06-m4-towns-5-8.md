## 5. Task 목록 (Task 37 ~ Task 41)

**Phase 1 (4개 병렬)**
- **Task 37** — 희생(sacrifice) 마을 콘텐츠 — Dione (`map.town.sacrifice`)
- **Task 38** — 명예(honor) 마을 콘텐츠 — Argon (`map.town.honor`)
- **Task 39** — 영성(spirituality) 마을 콘텐츠 — Elia (`map.town.spirituality`)
- **Task 40** — 겸손(humility) 마을 콘텐츠 — Heron (`map.town.humility`)

각 task의 작업 (M3 패턴 반복):
1. `content/towns/<virtue>/maps.yaml` — M2 스텁을 28×20 마을 내부로.
2. `content/towns/<virtue>/npcs.yaml` — 8~12 NPC. (humility는 침묵 규칙 반영 — NPC가 짧게만 응답)
3. `content/towns/<virtue>/facts.yaml` — 12~16 fact.
4. `content/towns/<virtue>/deduction.yaml` — `deduction.<virtue>`.
5. `content/towns/<virtue>/crisis.yaml` — `crisis.<virtue>.<topic>`.
6. `content/towns/<virtue>/encounters.yaml` — 1~2 encounter.
7. `content/music/<virtue>.yaml` — 새 음악.
8. `content/abilities.yaml`에 ability id append (humility는 생략).
9. `content/creatures.yaml`에 creature id append.
10. `content/strings/ko.yaml`에 `<virtue>.` prefix로 새 키.
11. `assets/LEDGER.md`에 새 음악 행 1개.
12. `npm run check:content` 통과.
13. `npm run test:unit` 회귀 0.
14. 커밋: `content(<virtue>): town of <virtue> — ...`.

**Phase 2 (Task 41, 1 에이전트)**
- M4 시나리오 테스트 4개 + 통합 + 머지 게이트.
- main ff-merge·push → Pages 200 확인.
- `docs/handoff.md`에 M4 완료 절.

총 **5 Task** (37~41). Phase 1에서 4개 동시 실행.
