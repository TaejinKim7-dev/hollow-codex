## 2. 스펙과 다르게 정한 점

| # | 결정 | 근거 |
|---|---|---|
| D1 | PWA는 vite-plugin-pwa 사용 — `public/manifest.webmanifest` 자동 생성, Workbox로 캐시 | 기존 빌드는 Vite 6 + Rollup이므로 plugin 생태계가 자연스러움. |
| D2 | 영어(i18n)는 스킵 — spec §8 "(선택) 영어". 사용자에게 옵션. | 우선순위 낮음. |
| D3 | 모바일 가상 게임패드는 만들지 않음 — 키보드/터치 직접 조작으로 충분 (M1 입력 시스템이 이미 지원). | spec §4.8 "터치: 누르면 길찾기 이동, 칩 대화" — 이미 구현됨. |
| D4 | 접근성은 Lighthouse a11y ≥ 95를 목표 — 색 명도·ARIA·키보드 포커스·alt 텍스트. | spec §7 "PWA + 접근성". |
| D5 | 이름 "Hollow Codex" 재확인은 단순 웹 검색 + GitHub 검색으로 충돌 없음 확인 (별도 워커 불필요). | handoff에 메모. |

## 4. Task 목록 (Task 45 ~ Task 48)

**Phase 1 (3개 병렬)**
- **Task 45** — PWA (vite-plugin-pwa 도입 + manifest.webmanifest + 아이콘 PNG + Workbox 오프라인)
- **Task 46** — 접근성 (모든 버튼·패널·dialog에 aria-label, focus-visible CSS, 명도 4.5:1, alt 텍스트)
- **Task 47** — README + 크레딧 + 이름 재확인 + 모바일 미세 조정

각 task의 작업:
1. **Task 45**:
   - `package.json`에 `vite-plugin-pwa` 추가 (devDep).
   - `vite.config.ts`에 plugin 추가 (`generateSW`, manifest 옵션).
   - `public/icon-192.png`, `public/icon-512.png` 생성 (Kenney 16×16 스프라이트시트에서 한 비트맵을 192/512로 업스케일, 또는 새 16×16 시드 → 권장: `assets/tiles/kenney-tiny-town.png`의 16×16 단일 타일을 192×192/512×512로 NEAREST 업스케일).
   - `public/manifest.webmanifest` — name, short_name, start_url (`/hollow-codex/`), display `standalone`, icons.
   - `index.html` — `<link rel="manifest">`, theme-color, apple-touch-icon.
   - 빌드 시 service worker 생성; `npm run preview`로 확인 (오프라인 모드).
   - `tests/e2e/boot.spec.ts` (M1) 확장 — manifest link 존재 확인 (선택).

2. **Task 46**:
   - `src/ui/panels.ts` 모든 버튼에 `aria-label` 추가 (한국어 라벨 그대로 써도 됨, 또는 별도 `aria-label` key).
   - `src/ui/panels.css` `:focus-visible` 스타일 추가 (키보드 포커스 표시).
   - 색 명도 검사 — NeoDungeon(`#eee` 배경, `#111` 글자)는 4.5:1 충족. 버튼 호버 색은 3:1 충족 확인.
   - `<canvas>`에 `aria-label="게임 화면"` 추가.
   - 모든 NPC 이름·dialogue text가 한국어인데 sr-only 대체 텍스트 제공 (spec: "alt 텍스트" — 텍스트 콘텐츠는 sr 지원이므로 라벨만 충분).

3. **Task 47**:
   - `README.md` 전면 개편 — 게임 소개, 설치, 플레이 방법, 빌드, 라이선스, 기여.
   - 크레딧 강화 — credits 패널(메뉴 → `ui.credits`)에 외부 자산 출처 + 라이선스 + 작가 모두 표시 (현재 `credits` 패널은 단순 표시 — LEDGER 데이터를 더 잘 정리).
   - `content/strings/ko.yaml`에 `ui.credits-intro` 같은 키 추가 (한국어 크레딧 화면 인트로).
   - 모바일 미세 조정 — 터치 영역 44×44px 이미 만족 (M1). 추가: 모바일 세로 모드에서 메뉴 버튼 위치 점검.
   - 이름 재확인 — `docs/handoff.md`에 "Hollow Codex" 검색 결과 메모 (별도 충돌 없음 확인).
   - `assets/LEDGER.md` 최종 점검 — 모든 자산 행이 정확한지.
