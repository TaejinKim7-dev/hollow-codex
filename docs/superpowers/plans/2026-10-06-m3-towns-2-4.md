## 5. Task 목록 (Task 33 ~ Task 36)

**Phase 1 (3개 병렬)**
- **Task 33** — 연민(compassion) 마을 콘텐츠 — Reona (`map.town.compassion`)
- **Task 34** — 용맹(valor) 마을 콘텐츠 — Solgang (`map.town.valor`)
- **Task 35** — 정의(justice) 마을 콘텐츠 — Seles (`map.town.justice`)

각 task의 작업:
1. `content/towns/<virtue>/maps.yaml` — 스텁을 24×18 (또는 더 큰) 마을 내부로 교체 (입구 + 광장 + 건물 + NPC 위치).
2. `content/towns/<virtue>/npcs.yaml` — 8~12 NPC. `pos`는 walkable 셀. `name` / `job` 토픽 + 미덕 관련 추가 토픽.
3. `content/towns/<virtue>/facts.yaml` — 12~16 fact (각 kind 최소 1개, 단어 4~6개).
4. `content/towns/<virtue>/deduction.yaml` — `deduction.<virtue>` (sentenceKey/hintKey/answer/unlocks).
5. `content/towns/<virtue>/crisis.yaml` — `crisis.<virtue>.<topic>` (npc + 2~3 option).
6. `content/towns/<virtue>/encounters.yaml` — 1~2 encounter.
7. `content/music/<virtue>.yaml` — 새 음악 (공유 저작물 편곡 + 자작 battle loop).
8. `content/abilities.yaml`에 ability id append.
9. `content/creatures.yaml`에 creature id append.
10. `content/strings/ko.yaml`에 `<virtue>.` prefix로 새 키 (NPC 이름·대사·fact·deduction·crisis·ability·creature·music 이름).
11. `assets/LEDGER.md`에 새 음악 행 1개.
12. `npm run check:content` 통과 확인.
13. `npm run test:unit` 통과 확인 (회귀 0).
14. 커밋: `content(<virtue>): town of <virtue> — maps, people, deduction, crisis, encounters, music`.

**Phase 2 (Task 36, 1 에이전트)**
- **Task 36** — 시나리오 테스트 + 통합 + main 머지·push
  1. `tests/scenario/m3-<virtue>.test.ts` 3개: 각 마을 한 바퀴 (입장 → NPC 대화 → 추론 확정 → 위기 풀기).
  2. merge 게이트 (npm ci, test:unit, typecheck, check:content, build, audit:dist, diff-check) exit 0.
  3. `docs/handoff.md`에 M3 완료 절 추가.
  4. main ff-merge·push → Pages 200 확인.

총 **4 Task** (33~36). Phase 1에서 3개 동시 실행, Phase 2는 순차.
