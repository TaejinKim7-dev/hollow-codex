# 빈 경전 (Hollow Codex)

브라우저에서 바로 하는 한국어 우선 지식 기반 탐험 RPG.

미덕이 제도가 되어 굳어 버린 대륙 **알마(Alma)**. 이방인인 당신은 이름을 외우는 대신 사람들과 대화하며 단서를 모으고, 흩어진 지식을 엮어 **여덟 미덕(정직·연민·용맹·정의·희생·명예·영성·겸손)** 의 본래 뜻을 되찾는다. 레벨이 아니라 "알게 된 것"이 길을 열고, 여덟 마을의 위기를 이해로 풀어 간다. 마지막에는 봉인된 서고에서 **비어 있는 경전**을 펼치고, 자기 답을 직접 써 넣는다. 악당은 없다. 선의로 굳어 버린 제도가 사람을 옥죄는 이야기다.

## 1. 게임 소개

- **장르**: 지식 기반 탐험 RPG (Outer Wilds·Tunic·Golden Idol 계열의 추리 구조)
- **핵심**: NPC와 나눈 대화, 읽은 글, 관찰한 사건이 모두 단서(fact)가 된다. 단서를 3칸 추론 문장에 끼워 맞춰 미덕의 본래 뜻을 확정하면 능력이 열린다.
- **세계**: 대륙 1개, 마을 8개(미덕당 하나), 열석 고리로 이어지는 이동, 봉인된 서고.
- **전투**: 적고 의미 있는 격자 턴제. 적의 다음 행동이 미리 보이고, "이 존재가 정말 악한가"를 생물 도감으로 판단한다. 악하지 않은 존재를 해치면 행실에 기록된다.
- **동료**: 마을마다 한 명. 행실이 그 동료의 미덕과 어긋나면 떠난다.
- **엔딩**: 마지막 장에 무엇을 쓰느냐에 따라 마을들의 에필로그가 달라진다.

## 2. 플레이

- **플랫폼**: 데스크톱 웹(키보드 + 마우스)과 모바일 웹(터치). 설치형 PWA로도 쓸 수 있다.
- **언어**: 한국어 우선.
- **분량**: 첫 완결까지 6~10시간.
- **가격**: 무료.
- **조작**
  - 이동: 방향 키/WASD, 또는 화면을 눌러 길찾기 이동.
  - 대화: NPC에게 다가가 주제 칩을 누른다.
  - 수첩/메뉴/고리/경전: 화면 구석 버튼 또는 키보드.
  - 키보드만으로 모든 패널을 열고 닫을 수 있으며(`Escape`로 닫기), 초점 표시가 보인다.

## 4. 기술

- **언어/도구**: TypeScript + Vite.
- **core 순수성**: `src/core/**`는 DOM·Canvas·Audio·`Math.random`에 의존하지 않는다. 난수는 `state.rng` 시드로만 쓰고, core 함수는 입력 상태를 바꾸지 않고 새 상태를 돌려준다.
- **렌더링**: Canvas 2D, 16×16 타일 정수 배율.
- **오디오**: Web Audio 기반 칩 사운드 합성(텍스트 악보).
- **콘텐츠**: YAML 데이터 주도. 화면 문구는 `content/strings/ko.yaml`의 키로만 꺼낸다.
- **개발 방식**: TDD — 실패하는 테스트를 먼저 쓰고 최소 구현으로 통과시킨 뒤 리팩터링한다.

```bash
npm run test:unit     # 단위 + 시나리오 테스트
npm run typecheck     # tsc --noEmit
npm run check:content # 콘텐츠 컴파일 + 금지어 + 자산 장부 검사
npm run build         # 프로덕션 빌드(dist/)
npm run audit:dist    # dist/ 외부 출처·예산 감사
```

## 7. 기여

- 이슈와 PR을 환영한다. 큰 변경은 먼저 이슈로 상의하는 편이 좋다.
- 원작(참고 게임)의 고유명사·문장·음악·번역을 가져오지 않는다. 개념만 계승하고 이름과 글은 새로 만든다.

```bash

npm run typecheck
npm run check:content
npm run build
npm run audit:dist
```

- `content/ip-denylist.yaml`의 금지어 검사를 통과해야 한다. `content/`, `src/`, `scripts/`, `tests/` 어디에도 금지 이름·문장을 쓰지 않는다(주석 포함).

## 8. 원작과의 경계

이 게임은 설계 스펙 §2의 IP 경계를 따른다.

- **아이디어만 계승**: 여덟 미덕과 그 바탕인 세 원리(진실·사랑·용기)의 구조, 악당 없이 스스로를 시험하는 구도, 키워드로 묻는 대화, 행실에 따라 동료가 떠나는 규칙, 마지막에 미덕에 관한 답을 요구하는 엔딩. 이는 일반적인 개념 수준의 오마주다.
- **일절 쓰지 않음**: 원작의 고유명사(상표·지명·인물·유물 체계), 원작의 문장과 그 번역, 원곡 음악과 그 편곡. 모든 이름·대사·마을·노래는 이 프로젝트에서 새로 지었다.
- 이 규칙은 `content/ip-denylist.yaml`과 콘텐츠 검사기로 강제되며, 위반 시 빌드가 실패한다.
